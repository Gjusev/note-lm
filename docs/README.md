## Scope

This export contains the Next.js application, Convex functions and
documentation. The README describes the intended workflow; a fresh
end-to-end deployment was not re-verified for this export. The screenshots
are captures of the landing surface. No claim is made that external services,
API keys or a Convex deployment are available to a new clone.
